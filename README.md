# Calculadora de Consumo Eléctrico

## Descripción del proyecto

La Calculadora de Consumo Eléctrico es una aplicación de escritorio desarrollada en Java con interfaz gráfica Swing. Su objetivo es ayudar a los usuarios a estimar el consumo energético de los aparatos eléctricos de sus hogares.

## Objetivo

Promover el uso responsable de la energía eléctrica mediante el registro de aparatos y el cálculo de su consumo diario y mensual.

## Tecnologías utilizadas

- Java 25.
- Apache NetBeans IDE 31.
- Java Swing.
- Almacenamiento local mediante archivos de texto.

## Funcionalidades principales

- Registro de aparatos eléctricos.
- Captura de potencia en watts.
- Registro de horas de uso diario.
- Cálculo del consumo diario en kWh.
- Cálculo del consumo mensual estimado.
- Consulta del consumo total diario.
- Eliminación de aparatos registrados.
- Almacenamiento y recuperación de información mediante un archivo local.

## Fórmulas utilizadas

**Consumo diario:**

Consumo = (Potencia en watts × Horas de uso) / 1000

**Consumo mensual:**

Consumo diario × 30 días.

## Instalación y ejecución

1. Instalar Java JDK.
2. Instalar Apache NetBeans.
3. Descargar o clonar este repositorio.
4. Abrir el proyecto desde NetBeans.
5. Ejecutar la clase CalculadoraConsumoElectrico.

## Almacenamiento

Los registros se guardan localmente en el archivo `aparatos.txt`.

## Sostenibilidad

La aplicación busca fomentar la conciencia sobre el consumo energético, mediante herramientas sencillas que permiten identificar el gasto eléctrico de los aparatos domésticos.
